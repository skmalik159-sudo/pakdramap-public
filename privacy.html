Scope

This policy covers the application "PakDramaP YouTube Automation". The application is used only by its own operator to publish that operator's video content to a YouTube channel they own.

Whose data the application handles

The application does not have users other than its operator. It does not collect, request or receive personal information from any member of the public, and it has no sign-up, login or account system for third parties.

Google user data the application accesses

When the operator authorises the application with their own Google account, the application receives an OAuth token limited to two scopes:

  • https://www.googleapis.com/auth/youtube.upload — used solely to upload and schedule the operator's own videos to the operator's own channel.
  • https://www.googleapis.com/auth/youtube.readonly — used solely to confirm which channel the token belongs to, and to read back the status of those uploads.

The application does not read viewer data, subscriber lists, comments, analytics or any information about other people's Google accounts.

How the data is stored

The OAuth token is stored as an encrypted secret in the operator's own source-control account and is used only by the operator's automated publishing jobs. It is never printed in logs, never shared with third parties, and never transferred to any other service.

How the data is used

Only to perform the publishing action the operator has asked for. Google user data obtained through these scopes is not used for advertising, is not sold, is not transferred to others, and is not used to build any profile of any person.

Retention and deletion

The token is retained only while the automation is in use. The operator can revoke it at any time from the Google Account permissions page, which immediately and permanently ends the application's access. Revoking access deletes the application's ability to read or write anything in that Google account.

Other information

The application also reads publicly available television schedule pages and publicly available YouTube search results. That information is public, contains no private user data, and is used only to decide publishing timing.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be published at this address with a new "last updated" date.

Contact

Questions about this policy can be sent to the address published on the Google consent screen for this app.
